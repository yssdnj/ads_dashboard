# Consensus 入围广告活动命中明细 — 设计文档

**日期**：2026-05-25  
**状态**：已确认，待实施

---

## 背景

现有 Consensus 标签页展示「进入 consensus 的 targeting 列表」，但缺乏按广告层级聚合的视图，无法快速判断「哪些广告活动问题严重」。

本次新增「入围广告活动命中明细」区块，在三轮和六轮 consensus 面板中均展示，帮助用户从广告类别 → 广告组合 → 广告活动三个维度快速定位问题。

---

## 目标

1. 在 consensus 面板新增四层可折叠树：广告类别 → 广告组合 → 广告活动 → Targeting 明细
2. 每层折叠态只显示名称 + 入围 targeting 数量
3. Targeting 行展示命中轮次徽章 + 规则推断说明
4. 三轮和六轮 consensus 共用同一渲染逻辑
5. R1/R2/R3/R4/R5/R6 各轮面板不显示此区块

---

## UI 结构

插入位置：现有「层级明细」（第 9 节）**之前**，新增第 10 节标题「入围广告活动命中明细」。

```
📋 入围广告活动命中明细
├── [▶] 1_SP_KW精准  · 8 个 targeting
│    ├── [▶] 组合A  · 5 个 targeting
│    │    ├── [▶] Campaign-XXX  · 3 个 targeting
│    │    │    ├── keyword_abc | 精准 | ⚠️高ACoS | -10% | R1 R2 R3 | 近期持续异常，建议尽快处理
│    │    │    └── keyword_def | 词组 | ⚠️高ACoS | -8%  | R1 R3    | 近期复发，历史有前例
│    │    └── [▶] Campaign-YYY  · 2 个 targeting
│    └── [▶] (无组合)  · 3 个 targeting
└── [▶] 3_SP_ASIN精准  · 4 个 targeting
```

使用 `<details>/<summary>` 实现折叠，与现有「层级明细」风格一致。

## Targeting 行列定义

| 列 | 内容 | 说明 |
|----|------|------|
| Targeting | targeting 文本（超长截断+title） | — |
| Match | 匹配类型标签 | — |

| 说明 | 规则推断文字（≤15字） | 见下方规则表 |

## 说明列推断规则

规则按优先级从高到低匹配，取第一条满足的：

| 优先级 | 条件 | 说明文案 |
|--------|------|---------|
| 1 | 命中轮次 ≥ 5 | 长期持续异常，优先处理 |
| 2 | 包含 R1 且命中连续（如 R1,R2,R3 或 R1,R2,R3,R4） | 近期持续异常，建议尽快处理 |
| 3 | 包含 R1 且命中 ≥ 3 轮（非连续） | 近期复发，历史有前例 |
| 4 | 包含 R1 且命中 = 2 轮 | 近期出现，观察是否持续 |
| 5 | 不含 R1（其余轮次达到门槛） | 早期问题，近期已有改善迹象 |

**连续判断逻辑**：将命中轮次（R1/R2/R3/R4/R5/R6）映射为数字（1~6），检查是否构成连续递增序列（无跳跃）。

---

## 渲染位置与条件

- `renderTargetingResult` 函数中，通过 `roundKey` 判断：
  - `roundKey === 'consensus'` → 渲染此区块
  - 其他轮次 → 跳过

- 若 `rows.length === 0`，区块显示「暂无入围广告活动」占位文字，不报错。
